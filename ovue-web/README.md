## 폰트
- 사이트 전체 폰트: **G마켓 산스** (Light 300 / Medium 500 / Bold 700) — 업체 제공 원본 OTF를 woff2로 변환해 `fonts/`에 포함 (외부 CDN 불필요)
- 용량 최적화: 자주 쓰는 한글 2,350자 + 자모 + 영문·숫자·기호 + 페이지에 쓰인 모든 글자만 남김 (3종 합계 1.26MB → 약 430KB). 목록에 없는 드문 글자는 기기 기본 폰트로 표시됩니다.
- 문구에 드문 글자를 새로 넣었다면 `fonts/subset-chars.txt`에 그 글자를 추가하고 원본 OTF로 다시 생성하세요:
  `pyftsubset GmarketSansMedium.otf --text-file=fonts/subset-chars.txt --flavor=woff2 --layout-features='*' --output-file=fonts/GmarketSansMedium.woff2` (Light·Bold도 동일)

## 로고 (`assets/`)
업체 로고 이미지를 벡터(SVG)로 변환해 웹용으로 정리했습니다.
- `ovue-logo-gold.svg` / `ovue-logo-white.svg` — 전체 로고 (Website Creation 포함): 푸터 등 넓은 자리
- `ovue-badge-gold.svg` / `ovue-badge-white.svg` — 태그라인 없는 로고: 헤더 등 작은 자리
- `favicon.svg` — 브라우저 탭 아이콘 (네이비 바탕 + 금색 창틀 + O.)

## 첫 화면 (밤의 풀빌라 컨셉)
- 3초 인트로: 로고 모양 브라우저 창 테두리가 금색 가는 선으로 그려짐(0~0.7초) → 불 꺼진 밤 풍경이 아래에서 차오름(~1.5초) → 창문 불이 왼쪽부터 하나씩 켜지고 수면 반사도 따라 켜짐(~2.6초) → 창이 살짝 기울며 설명 문구 등장(~3초)
- 첫 화면은 그림(브라우저 창)과 설명 한 줄(‘공간의 분위기와 온도까지…’ + ‘상담 문의’ 링크)로 된 한 섹션. 헤더 아래 화면 높이를 꽉 채우고 상하좌우 24px 안팎 여백만 둠(그림 크기는 화면 높이에 맞춰 자동 계산). 그림 속 글자는 모두 없음. 검색엔진·스크린리더용 제목(h1)은 화면에 보이지 않게 남겨 둠
- 장면: 집·야자수·소나무·데크·선베드·실내 실루엣을 하나의 평면 일러스트(SVG)로 그림. 수면은 WebGL 셰이더(직접 작성)로 같은 그림체에 맞춘 ‘밤 수면’ — 차분한 청록~남색, 느린 잔물결, 창문 불빛과 달이 흔들리며 끊기는 반사, 수영장 벽 쪽 수중 조명 3개. 마우스 근처 수면이 은은하게 밝아짐. 화면 밖이면 멈춤
- 같은 방문 중 재방문 시 인트로 0.3배 속도, ‘건너뛰기’ 버튼 제공. ‘동작 줄이기’ 설정이면 인트로 없이 완성 화면 표시
- 히어로 속 사이트 ‘LUMI’는 가상 브랜드 예시 (실제 풀빌라 포트폴리오가 생기면 사진으로 교체)
- 히어로 아래 띠 대신 3D 쇼케이스(C안): 기울어진 3D 평면 위에 업종별 사이트 썸네일 9종(풀빌라·숲속 펜션·오션뷰 스테이·글램핑·한옥 스테이·카페·인테리어·학원·제조업)이 3줄로 서로 반대 방향으로 흐름. 마우스를 올리면 멈추고 카드가 떠오름. 화면 밖이면 멈춤, ‘동작 줄이기’면 정지. (B안 3D 키워드 링은 커밋 c6f06aa에 있음)
- 톤: ‘밤 → 새벽 → 아침’으로 이어지는 하나의 그라데이션. 밤(첫 화면·쇼케이스·강점·비교: 남색→인디고→로열블루, 물빛·보랏빛 번짐) → 새벽(포트폴리오 상단: 페리윙클→라벤더, 복숭아빛 여명) → 아침(요금 하늘빛, 구성 아쿠아빛, 진행 과정 라벤더빛, 오픈 후 지원 피치빛, FAQ·상담·푸터는 흰색으로). 각 섹션 끝 색 = 다음 섹션 시작 색이고, 빛 번짐은 섹션 안에서 사라지게 배치해 경계선이 보이지 않음
- 푸터: 흰 바탕에 사이트 포인트 그라데이션(아쿠아→블루→바이올렛→피치)을 상단 라인·모서리 빛 번짐·항목명 글자·링크 밑줄에 사용. 하단 대형 ‘O.Vue WEB’ 워드마크는 4.8초마다 빛 줄기가 한 글자씩 순서대로 지나가며 글자마다 같은 색 후광이 켜졌다 꺼지고 살짝 떠오름(마우스 없이 자동 반복, 화면 밖이면 멈춤, ‘동작 줄이기’면 정지)
- 첫 화면 정돈: 배경 색 번짐 축소, 옅은 필름 질감 + 가장자리 어둡게, 3D 기울기·그림자 약화, 문구 줄 위 가는 구분선과 ‘O.Vue WEB — Website Creation’ 라벨
